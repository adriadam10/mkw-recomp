# tests/runtime

Pieces of `runtime/` built alone: audio, controllers, memory caps, settings and the menu's texts.

| File | What it checks |
|---|---|
| `test_ui_text.py` | The menu's text catalogs (`i18n/`): the English template has every id of `ui_text.h`, each `.po` is up to date with it, and each translation keeps the English's printf conversions in order (a swapped `%s`/`%d` would make printf read the wrong argument) |
| `test_switch2.py` | The Switch 2 controllers' Bluetooth LE protocol (`runtime/input/switch2_proto.h`): mkw-neo's test (`t_switch2.c`, reports recorded from real Joy-Con 2s) built against our copy |
| `test_cfg.py` | `cfg.c` keeps one table: every key once, one row per line, the key-only rows in order (a key missing from the list made the menu's `HDR` setting drop as unknown, #168) |
| `test_cfg_bool.py` | `cfg_bool` (`cfg.c`), built alone with stubbed table lookups: `off`, `false`, `no` are false and `on`, `true`, `yes` true in any case, other numbers true, an unknown word gives the row's default |
| `test_crumbs_idle.py` | The device-loss breadcrumb report (`runtime/gfx/vk/diag/vk_crumbs.c`): with every started mark finished, as in issue #557's GTX 1080 log, it says no marked work was running |
| `test_linux_rpath.py` | The Linux `mkw` finds the `lib/` beside it (`tools/build/build.py` link flags, #825 #839 #840: code 127, `libvpx.so.6` missing, when a launcher runs `mkw` without the AppRun's `LD_LIBRARY_PATH`): the flag as `build.py` spells it, built with ninja into a program that is run from another folder without `LD_LIBRARY_PATH`; moving `lib/` away gives the loader's error again (Linux only) |
| `test_sparse_mib.py` | How `MKW_SPARSE_MIB` is parsed (`runtime/gfx/vk/tex/vk_sparse.c`): whole MiB only, so a typo or a negative value keeps the GPU's default instead of lifting or wrapping the cap |
| `test_defaults.py` | The memory caps a player gets with nothing set (`runtime/gfx/vk/device/vk_defaults.c`), built alone and checked on the GPUs players reported: the Radeon 660M keeps its measured caps, a large discrete GPU is not held to them (issue #31) |
| `test_gfx9_block_ca.py` | The GFX9 RADV guard on block-view COLOR_ATTACHMENT (`runtime/gfx/vk/tex/vk_tex_gfx9.c`), built alone: RADV's pre-RDNA maxImageDimension3D of 2048 skips COLOR_ATTACHMENT for a 3D block-compressed image with mips and depth in blocks (the shape addrlib's swizzle filter empties into a SIGTRAP, the Vega 7 crash of #385), and RDNA, other drivers, 2D, one mip and shallow depth keep their block views |
| `test_lazy_pool.py` | Lazy Vulkan pool backing (`vk_mem_back.c`), built with the allocation stubbed: failed backing counts once and successful backing publishes the buffer without counting a failure |
| `test_lazy_fault.py` | Windows' lazy commit hook (`lazy_fault` in `runtime/core/memory/memory.c`, cut out and built with the page state scripted): a read of a page another thread committed after the fault retries, also when it is frozen again (it went to the crash handler); a write of a committed page goes on to `thaw_fault`; a reserved page is committed and retried, one the game does not own is not |
| `test_mem_readable.py` | `plat_mem_readable` of both platforms (`runtime/platform/linux_mem.c`, `win32_mem.c`, cut out and built together with the memory scripted): a range up to or past 2^64 is no memory, as a frame walk's 16 bytes at `0xfffffffffffffff8` (Linux said yes) or a size that wraps from a committed address (both said yes); ranges inside and past the readable memory as before |
| `test_audio_update.py` | The actual audren RequestUpdate parser (`runtime/audio/audren.c`, its section cut out and built alone) with synthetic REV11/REV15 records: zeroed unused slots cannot reset playing voice 0, freed slots stop, reused slots reset and output status stays with its slot |
| `test_adpcm.py` | DSP-ADPCM voices (`runtime/audio/audio_mixer.c`, its voice decoding cut out and built alone) against an exact decode of random buffers (`t_adpcm.c`): with a context on every buffer, loops included, the output is the exact decode; without contexts at most a few samples differ (a slot refilled before the walk decoded its last samples); high pitch and sample rate cross more than 128 input samples at once; each sample is decoded about once (#331) |
| `test_mem_limit_mib.py` | How `MKW_GPU_MEM_LIMIT` and `MKW_VRAM_MARGIN` are parsed (`runtime/gfx/vk/device/vk_device.c`): whole MiB only, so a typo keeps the default cap and margin instead of lifting or wrapping them |
| `test_mod_settings.py` | A mod's settings per player (`runtime/plugin/mod_settings.c`, built alone with `t_mod_settings.c`): values round-trip, a set replaces only its key and NULL removes it, two mods or two players never share a file, and invalid keys, values and mod names are refused |
| `test_host_pages.py` | Guest pages of 4 KiB on larger host pages (`runtime/platform/linux_mem.c`, built alone with `t_host_pages.c`), with the kernel's pages and as 16 and 64 KiB ones (`MKW_HOST_PAGE_KIB`): a protection on part of a host page never fails and never takes a neighbour's access, a whole host page gets exactly what was asked, a decommitted guest page reads zero when committed again with its neighbours' bytes kept, and the write watch loses no written page (a one-page peek, a reset whose room ends inside a host page, two ranges sharing one); a bad `MKW_HOST_PAGE_KIB` warns and keeps the kernel's size. Linux only; the shared host page's marks are only really at stake on a kernel with larger pages (Apple silicon) |
| `test_power.py` | Xbox pads on Linux's xone driver (`runtime/input/linux_power.c`, built alone with `t_power.c`): the sysfs level band reads as High/Medium/Low, never a percent; charging, full, no battery pack (wired) and per-Xbox-pad order; a non-Xbox pad never takes an Xbox level; the laptop battery is ignored |
| `test_nup.py` | The runtime's `.nup` reader (`runtime/sdk/fs/nup.c`, built alone with `t_nup.c`) against the setup's (`tools/prepare/nup.py`) on packages of several titles, as Eglantine's `--pack-nup` writes the base game and an update: the same files, the update's over the base's, its ExeFS whole, DLC and the table's order ignored, a package of one title as before |
| `test_plat_jmp.py` | Windows' own `plat_setjmp`/`plat_longjmp` (`runtime/platform/win32_jmp.c`, a guest thread's exit without ucrtbase's `longjmp`), built with llvm-mingw and run under wine; skipped without them |
| `test_framegen.py` | Frame generation's factor (`runtime/gfx/vk/device/vk_framegen.c`, its selector cut out and built alone with the display stubbed): the 120 fps target (60 x2, 30 x4) on 60-240 Hz and fractional refreshes, the swapchain's room, the uneven-refresh note with and without VRR, movies and turbo, and the existing Automatic and fixed factors |
| `test_flip_pace.py` | Frame generation's requested step on the vblank clock (`runtime/gfx/vk/device/vk_backend.c`, its pure scheduler cut out and built with a deterministic clock): two-refresh spacing for 60 -> 120 at 240 Hz and FSR 2x at 30 fps on 119.88 Hz, balanced one/two-refresh gaps at 144 Hz, per-picture slot indexes, and late recovery without reusing a mailbox flip; without the clock (immediate), no picture within half a step of the flip before, a late flip caught up half a step at a time |
| `test_flip_pace.py` | Frame generation's requested step on the vblank clock (`runtime/gfx/vk/device/vk_backend.c`, its pure scheduler cut out and built with a deterministic clock): two-refresh spacing for 60 -> 120 at 240 Hz and FSR 2x at 30 fps on 119.88 Hz, balanced one/two-refresh gaps at 144 Hz, per-picture slot indexes, and late recovery without reusing a mailbox flip; a job's first picture at the first call's slot, so a job of one picture (frame generation's first frame after a pause, a menu or a gap) flips its game frame there and not a refresh later |

C sources the tests here build with the compiler at hand and run:

| File | Built by | What it checks |
|---|---|---|
| `t_switch2.c` | `test_switch2.py` | The Switch 2 controllers' protocol (`runtime/input/switch2_proto.h`): from seedds/mkw-neo (MIT), with reports and replies recorded from a left and a right Joy-Con 2 |
| `t_audio_update.c` | `test_audio_update.py` | Voice slots in RequestUpdate: `audren.c`'s update section (`request.inc`, cut out by the test) with the mixer and platform stubbed |
| `t_plat_jmp.c` | `test_plat_jmp.py` | A jump out of a deep call chain keeps the callee-saved integer and xmm registers, MXCSR and the x87 control word, and returns its value (0 as 1) |
| `t_nup.c` | `test_nup.py` | Lists a package's files as `nup.c` gives them to the RomFS (the platform layer stubbed on stdio); `t_nup PACKAGE count` only counts them, also on a real package |
| `t_adpcm.c` | `test_adpcm.py` | DSP-ADPCM voices: `audio_mixer.c`'s voice decoding (`voice.inc`, cut out by the test) against an exact decode of the same random buffers, five sample rates, seven pitches up to 3.9 (plus a high-rate case at 192 kHz and pitch 64), with and without contexts; prints output samples, wrong samples and decodes |
| `t_mod_settings.c` | `test_mod_settings.py` | A mod's settings: `mod_settings.c` with the platform's file and lock calls stubbed on stdio; prints ok or the failed check |
| `t_host_pages.c` | `test_host_pages.py` | Protections, decommits and the write watch on a reservation, with a fault probe for what the host really allows; prints the host page size, then `ok` |
| `t_power.c` | `test_power.py` | Xbox batteries on xone: `linux_power.c` against a fake sysfs tree; prints found, state, percent and coarse |
| `t_renhdrum.c`, `t_renhdrum_dll.c` | `test_renhdrum.py` | `renhdrum_host_win.c` and the vendored RenHDrum bridge (Windows only) with `cfg.h`, `host.h`, `platform.h` and `SDL.h` stubbed (headers the test writes): with `MKW_RENHDRUM` off, on without `renhdrum.dll`, with a mock DLL of another version and with one of the right version, every call is harmless, nothing claims the gamepad, and the log says why RenHDrum is not used |
