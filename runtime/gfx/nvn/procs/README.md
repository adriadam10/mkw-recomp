# runtime/gfx/nvn/procs

The NVN1 and NVN2 function tables handed out by `nvnDeviceGetProcAddress`, and NVN2's own functions.

| File | What it is |
|---|---|
| `nvn.h` | NVN1 types and signatures (h1k421, MIT) |
| `nvn_procs.c`, `nvn_procs.inc` | NVN1 function table handed out by `nvnDeviceGetProcAddress` (NVN1 names from totk-pc-recomp, generated) |
| `nvn2.c` | MKW's own: NVN2 functions (ProgramBuilder, sparse textures, state hints; push constants and mesh dropped with a warning; ray tracing and VRS off) |
| `nvn2_procs.inc`, `nvn2_devinfo.inc`, `nvn2_devinfo_180.inc` | MKW's own, generated by `tools/gpu/`: NVN2 functions with no NVN1 equivalent (weak stubs; the union of every version's sdk) and the answers of `nvnDeviceGetInteger` (1.0.0's driver, API 231.16, and 1.8.0's, 231.39) |
