# runtime/gfx/vk/spv

SPIR-V of the runtime's own shaders, generated by `tools/shaders/embed_spv.py` from `runtime/shaders/`; not edited.

| File | What it is |
|---|---|
| `*_spv.h` | Embedded SPIR-V of `runtime/shaders/` (`astc_decode`, `bc1_encode`, `bc7_encode`, `clk_busy`, `fg_flow`, `fg_luma`, `fg_median`, `fg_synth`, `fsr_easu`, `fsr_rcas`, `hdr_fullscreen`, `hdr_ui`, `mesh_compact`, `solid`); generated, not edited |
| `tmp_mv_spv.h` | `shaders/temporal/tmp_mv.comp`: the temporal upscalers' camera motion vectors and R32F depth (`exec/vk_temporal.c`) |
| `fg_hud_spv.h` | `shaders/framegen/fg_hud.comp`: the game frame's HUD over the made frames of DLSS-G and FSR 3.1 (`device/vk_framegen.c`) |
| `of_luma_spv.h`, `of_mv_spv.h` | Optional hardware optical-flow inputs and packed-vector conversion (`device/vk_oflow.c`, `device/vk_framegen.c`) |
| `tmp_cas_spv.h` | `shaders/temporal/tmp_cas.comp`: contrast adaptive sharpening of the upscaler's picture (`exec/vk_temporal.c`) |
| `ffx_game_field_spv.h` | Production StillTie kernel derived from AMD FidelityFX-SDK 2.4.0; regenerate with `uv run tools/ffx/builder/build.py`, then copy its verified `out/include` header explicitly |
